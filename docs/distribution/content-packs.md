# Share and install a Prowess content pack

## Export a published Release

Open **Compendium → Rules Reference**, choose the Ruleset and the exact published Release, then select **Export for Players**. Share the downloaded `.prowesspack` file. It carries that Release's portable records, required exact revisions and any supported archived media supplied by an existing pack.

## Preview and install

1. Open Studio from the desktop launcher and choose **Compendium → Content Packs**.
2. Select the `.prowesspack` file and choose **Preview pack**. Review its publisher claim, Release and proposed records. Files installed manually display **Unverified source**.
3. Choose **Install pack** once the preview shows **Ready**. Repeating a completed import shows **Already installed**. A changed catalog requires a new preview.
4. Open **Characters → New Character** to choose an installed Release. Saved Characters retain the Release they started on.

A content pack carries released rules. Use **Manage workspace → Back up workspace** to save Characters, play history, installed content and receipts for recovery. On an empty installation, **Demo — sample rules** runs the same pack checks on the included sample Release.
